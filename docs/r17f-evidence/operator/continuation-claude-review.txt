Two minor defects (neither affects measurement integrity):

1. **`main()` has no failure wrapper, so pre-run failures exit 1 with an unhandled-rejection trace instead of the runner's `BLOCKED …` + exit 2 convention** (`resume-remaining.mjs:32-50`). `continuationPlan` throws and the `wx` receipt `EEXIST` both escape past top-level await; `r17f.mjs:292-296` wraps the equivalent path in `catch { console.error('BLOCKED: …'); process.exitCode = 2 }`. It fails loudly either way, but an operator/harness keying on the joined exit-2 signal will see a different code for "refused to continue" than for "halted mid-run."

2. **The receipt is written before `run`'s preflight, so a benign preflight failure burns both fixed names** (`resume-remaining.mjs:46` before `:48`).
