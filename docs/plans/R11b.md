# R11b — bounded GET web fetch

`web_fetch({url})` is a core export and registered built-in (including CLI/children), declaring
`net` and external result provenance. The strict input accepts a credential-free HTTP(S) URL
of at most 4096 characters; no methods, headers or bodies can be supplied. Fragments are removed
before GET. Native fetch sends fixed Accept/User-Agent headers, no authorization or cookie
headers, and `credentials: omit`. URL query secrets remain caller-supplied data recorded in
ordinary tool/permission logs; this is not a credential-redaction facility.

Every redirect is refused; no destination is silently followed. Non-success status and anything
except text/plain or text/html are refused, with response bodies cancelled. A 10-second total
request/body deadline composes with session cancellation. Streaming collection caps decoded
bytes at 1 MiB regardless of declared length or compression. A declared oversized length also
refuses conservatively. Returned text is at most 20,000 UTF-16 code units without a split
surrogate pair; ordinary core display bounds can shorten it further. Truncation is explicit;
the unreturned remainder is not persisted as a complete output artifact.

Bytes decode as UTF-8 (other charset declarations are not implemented). HTML extraction is a
linear lexical approximation: omit comments/script/style/tag markup; decode common named and
numeric entities; collapse whitespace. It does not execute scripts, fetch resources, interpret
CSS, render a browser, sanitize HTML for embedding, or implement general readability. Malformed
markup can lose text. Plain text is returned as received, bounded. All returned content remains
untrusted external context; model-visible text grants no authority.

The R11a runtime gate and the tool's direct-SDK policy check independently refuse non-none
no-network policy. Explicit `--allow net`/YOLO is not sandbox-network permission. Both permission
allow and explicit network policy permit the trusted host fetch; an existing fresh one-time
sandbox escape is a distinct outside execution. None mode has no OS isolation. This bounded
host implementation is not contained by Docker/Seatbelt, and arbitrary trusted JavaScript is
not sandboxed. There is no SSRF/private-network filtering, hostname grant, ambient auth loading,
search provider, new config surface, or claim of remote side-effect freedom from HTTP GET.
