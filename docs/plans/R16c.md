## Contract

- No core, event schema, tool execution, permission, supervisor, memory, provider,
  replay or log mutation. A CLI-only fold renders observed events, not authority.
- Completed calls produce a sanitized one-line tool/key-argument/observed elapsed/
  outcome summary. Only primitive known key arguments are selected; no file reads,
  parsing output claims or inferred execution. Invalid/missing elapsed stays unknown.
  Existing live activity still describes running tools; missing terminal results
  flush as incomplete rather than invented success.
- Collapse only successful matched `read_file` calls with literal path, protected
  `tool.result.permission === read`, exact session/call-sequence/id correlation,
  and no internal/diagnostic/denied/unknown result. Names alone never establish
  read-class status. Label `read N files · N requests, repeats counted` so neither
  unique filesystem identities nor semantic success is claimed. Other read-class
  tools remain individual summaries; unknown legacy metadata never collapses.
- Preserve errors, denials, questions, permission asks, diagnostics and patched
  results visibly. These and other visible non-read boundaries flush read runs;
  only ordinary rule/fallback allow receipts may be hidden in compact mode but
  remain in verbose. Matched grants/approval-handler/boundary receipts stay visible.
  No output content, model-provided labels or UI aggregation can grant authority.
- At most 128 pending calls, 64 completed reads per run and 160 characters per
  compact line. Overflow flushes incomplete calls/runs with explicit markers, not
  silent dropping. Retain at most 128 sanitized raw lines / 64 KiB for expansion;
  bounded line projection and an explicit elision count prevent unbounded storage.
- `/verbose` on appends retained raw details, then uses the existing raw renderer
  for future events. Five collapsed reads restore five raw call lines plus their
  results. Static is append-only: prior compact lines cannot be erased/redrawn.
  Turning verbosity off affects future events; previously expanded lines are not
  re-appended by repeated toggles. R15c's disclosed-thinking semantics remain.
- Flush on visible boundaries, turn/session end, mode switch and shutdown. No
  wall-clock timer, runtime waits or changes to the existing viewport/wrapping.
  Aggregated elapsed is a sum of observed result durations, not parallel wall time.
