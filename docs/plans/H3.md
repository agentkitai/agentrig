# H3 — Preserve evidence before ingest coverage planning

## Contract

- Prefer authoritative assistant `message.append` text. Buffer streamed text per response and
  use a labeled uncommitted/legacy fallback only when no canonical assistant message follows.
  `model.response` carries accounting, not conclusions. Keep model claims distinct from tool evidence.
- Keep complete tool inputs and recorded `output` (otherwise `display`), plus full steering/error
  text. Record patched tool displays separately from original tool evidence. No prefix slicing.
  Denials distinguish requested operations from execution; overflow preview copies are labeled.
  Canonical-only tool requests/results survive interrupted logs, and nested images are omissions.
  The additive `tool.result.outputIncomplete` flag preserves tool collection limits even when
  a recorded-output artifact exists; it is distinct from display-only `truncated` accounting.
- Split the rendered transcript into bounded, lossless spans, including very long single lines.
  Preserve line coordinates and add exact half-open UTF-16 character offsets. Coverage describes
  inspected transcript ranges, not a claim that the model understood or verified every fact.
- Explicitly report missing full output in historical truncated-result events and unsupported
  non-text message evidence. Persist coverage/omission accounting on the source page as well as
  returning it. Missing/corrupt JSONL must fail before writes, not silently count as complete evidence;
  a session still writing a torn final record can be retried after the record is complete.

## Verification

Scripted-provider ingest must receive an assistant-only conclusion and decisive evidence beyond
character 500. Canonical messages must not duplicate streamed text; mixed legacy/current and
interrupted streams remain available with honest labels. Exact ranges reconstruct the transcript,
including blank lines and surrogate pairs, with every span bounded. Test missing output reports,
corrupt logs, repeated captures, and existing ingest/backend/hook regressions. Build/typecheck,
full suite, independent Claude review and cross-platform CI gate merge. Cancellation, maintenance
budgets and concurrency remain H5; structural promotion evidence validation remains H4.
