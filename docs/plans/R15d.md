# R15d — bounded remote MCP

Full row, one PR: Streamable HTTP, explicit OAuth login, resources/prompts and three-list
definition consent. Starts from green `74c5073` after R15b #185. R15a still requires ACP;
R15d's R11a/R5d dependencies are complete. No live auth/provider calls during verification.

## Contract

- Exact public `@modelcontextprotocol/client` 2.0.0 owns modern 2026-07-28/legacy 2025-11-25
  HTTP negotiation, JSON/SSE, OAuth and cancellation. Existing handwritten stdio handshake
  and process lifecycle remain compatible. No second protocol engine, old HTTP+SSE fallback,
  sampling/roots/elicitation/tasks/subscriptions or background cache.
- Strict stdio-or-URL configuration, at most16 servers and4KiB URL. HTTPS except literal
  loopback HTTP; no userinfo/fragments/embedded credentials. All remote operations require
  `net`, including startup discovery. Resources/prompts are read operations, not permission
  grants. Stdio tools retain exec, resource/prompt reads use read. No server hints authorize.
- Trusted host fetch requires explicit sandbox network policy, like web_fetch; not OS-contained
  JavaScript. Default/headless ask refuses before network. Later calls use normal permissions,
  grants, R13c and separate R5d consent. Startup approval never grants fresh user authority.
- Every SDK HTTP path, including auth, uses manual redirects, no cookies/ambient headers,
  endpoint/issuer constraints,10s whole-body deadline,1MiB decoded response/256KiB request.
  Logical MCP operations have30s/16 HTTP request caps and at most4 concurrent operations per
  server (excess refuses). SSE consumption remains bounded. No background reconnection or
  silent side-effect replay. Abort closes owned streams; close joins them, with at most2s
  best-effort legacy DELETE. Remote rollback/hostile containment are not promised.
- Explicit `mcp login` uses trusted config/policy, not a provider. SDK RFC9728 and RFC8414/OIDC
  discovery, exact configured issuer allowlist (max4) and permitted fetch origins constrain
  metadata/token/registration. Resource indicator equals the configured canonical MCP endpoint.
  Different-origin endpoints require explicit configuration; unsupported servers refuse honestly.
  R1 loopback state/listener is reused with whole callback params for SDK issuer validation.
  State/PKCE/issuer/redirect bind one120s live flow; crashes cancel rather than resume it.
  No raw OAuth errors are echoed. Public clientID, optional HTTPS client metadata URL or one
  SDK DCR registration; registration/browser/scope expansion only in operator login.
- Credentials are endpoint+issuer+client-ID bound, separate from provider credentials/config/logs.
  At most64KiB schema-validated regular non-symlink user files; atomic0600/0700 writes and
  Windows owner ACL before publication (failure refuses). Plaintext owner restriction, not
  encryption/keychain/admin isolation. Cooperative locks bound refresh/commit, never stolen.
  Invalid/changed issuer preserves prior secrets. Ordinary runs may refresh once but cannot
  register/open browser/expand scope. Plain doctor does not connect.
- Lists: at most20 pages and256 combined entries/1MiB. Tools, resources/templates and prompts
  are pinned with exact definitions and endpoint/capability identity, excluding credentials.
  Invalid/partial advertised lists refuse the server. Old tool-only pins are not reset: newly
  exposed definitions require separate consent. Uncached re-list before calls and after consent;
  existing CAS and any ACP require-existing-pins semantics are preserved.
- Opaque resource URIs only go to resources/read, never host filesystem/network resolution.
  Prompt args:32 keys,4KiB values,16KiB combined; displays20KiB with explicit omissions and
  collection1MiB. Returned roles/prose are external advisory content, never user instructions.
  Namespaced read/get tools and existing skill catalogue expose prompts; a narrow trusted loader
  uses the same net/pin checks and successful skill.used receipt. Local skills unchanged.
  Remote slash/model activation cannot upgrade source authority; no executable downloads.

## Verification / delivery

Actual local modern+legacy HTTP fixture with tools/resources/prompts and local OAuth issuer:
state/issuer/resource/redirect/token-store/refresh, changed-resource consent, ordinary denial,
YOLO/R13c distinction, SSE bounds/cancellation, uncached recheck, actual CLI/provider requests,
skills and storage/resume/compaction. Named detected/restored mutants; full build/typecheck,
