# E1 — frozen evaluation tasks

Scope: eight small, exploratory tasks across AgentRig and the external MIT-licensed is-number
repository. Freeze starting commits, deterministic fault seeds, task prompts, allowed changes
and independent checks before model runs. Include fixes, a behavior-preserving refactor,
investigations, repeated knowledge use and misleading/stale context.

Preparation exports only the pinned Git tree into a newly created directory, commits the seeded
baseline and keeps its receipt outside the workspace. Never reset, clean or overwrite an existing
checkout. A reset is another fresh preparation. Checks run from the evaluator checkout, not from
agent-authored tests; regression and behavioral results remain separate. This is not an OS sandbox.

Validate every task with a known passing artifact and a negative control, plus malformed receipts,
scope violations and existing/dirty workspace preservation. Build, typecheck, full Node22 suite,
one bounded independent Claude review and exact-head PR/main CI are the completion gates.

Non-goals: paid model runs, performance claims, general benchmark hosting or E2's event report.
The initial set is small and partly synthetic/public; disclose contamination and limited external
coverage. No recursive sub-milestones; optional polish goes at the END of ROADMAP.
