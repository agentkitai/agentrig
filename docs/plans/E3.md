## Preregistered protocol (before held-out calls)

- User-selected `gpt-5.6-luna`, `openai-chatgpt`, medium reasoning for every model role.
  Subscription only; no API-key fallback, credit purchases, or changed client identity.
  Connectivity already passed: 28 input / 5 output tokens, explicit end_turn.
- EVALSET v1: eight pinned tasks, four supervisor/memory combinations, three repetitions:
  96 held-out attempts. Latin-square rotation across task/repetition balances configuration
  position. Sequential runs avoid load and credential-refresh races. No result-driven retries.
- Main budget: 24 turns, 200,000 reported tokens, 5 minutes. Provider requests: 60 seconds,
  no automatic retries. Whole experiment: stop scheduling at 10 million reported tokens or
  12 hours, three incomplete calls, or any non-cancellation provider failure (including quota/auth).
  Reserve 1,178,000 tokens per incomplete call for scheduling only; never label it measured usage
  or a guaranteed billing bound. These are conservative operator-selected guards under
  the user's subscription-only authorization, not an exact subscription quota.
  Missing usage stays unknown; fewer than three expected cancellations do not discard the matrix.
  The outer hang guard allows 90 seconds past the normal five-minute turn-boundary budget.
  An in-flight response can exceed a token threshold because
  the backend does not accept max_output_tokens; abort cannot prove remote stop.
- Frozen training corpus: exactly EVALSET's separate is-number investigation and real SDK ingest.
  No held-out logs/answers/checks enter it. Every memory-on attempt gets a fresh copy;
  memory-off has no retrieval tools or injected index. No held-out ingest/dream: this measures
  frozen retrieval, not online learning. AgentRig tasks receive the same corpus, explicitly an
  irrelevant-memory control. Training cost/time is separate and included in experiment totals.
- Same minimal tools in every condition: isolated shell and update_plan, plus memory_search/
  memory_read only when enabled. Shell changes are observed for detector inputs; independent
  checks remain authoritative. No subagents, MCP, external memory backend, or compaction.
  Supervisor uses default heuristic detectors/ladder, bounded Luna reviewer and grader.
  The common system prompt discloses EVALSET's allowed test filenames and immutable inputs;
  several short E1 TASK.md prompts omit those mechanics. No expected answers are supplied.
- Task shell runs in a fresh Docker worker with no network, host credentials, Docker socket,
  evaluator or sibling-run mounts, with dropped capabilities and no-new-privileges.
  Provider calls and trusted orchestration stay outside. Checks run separately after the model
  worker stops. Record image identity, evaluator SHA and toolchain before runs.
- Preserve every run, exact logs/checks, diffs/new files, auxiliary receipts, timing,
  corpus digest, configuration and failures. Subscription consumption is reported in tokens;
  USD remains unknown/unpriced, not fictitious API spend.

## Hypotheses and decision rule

Primary: independent task success, not agent completion or model grader opinion. Per factor,
compare paired tasks/repetitions at the other factor's fixed setting. A useful exploratory signal
requires at least two additional passes among 24 attempts, no new regression/scope failures,
and no more than 25% median total-token or end-to-end-latency increase. Report interactions,
per-task outcomes, spread and missing evidence. Incomplete human judgments cannot establish a win.
Small/public/synthetic tasks and three repetitions cannot establish general superiority.
Mixed outcomes, absent interventions/retrieval, or ceiling effects are inconclusive. Keep features
opt-in unless criteria are met; do not redesign them inside this measurement PR.

A4/X4 retain their frozen **human** prose gates. Prepare an answer review packet for the user;
neither the maintainer model nor Claude may impersonate the human assessor. Automatic failures
remain failures; otherwise pending judgments remain BLOCKED. Do not advance to R4 while E3
acceptance is incomplete. Optional polish goes at the literal end of ROADMAP.
