# R13b — automatic source labels and conservative summaries

R13a delivered recursive metadata transport. This row assigns tool-result provenance from
trusted registration and retains a conservative source floor through built-in and custom
compaction. It implements no permission grants, hook/steer principals, injection detector or
web-fetch tool. R12e can proceed independently; its permission operation seam is separate.

Registered external sources (the actual MCP wrapper and future network adapters) yield
`external`; a lookalike name or model/server text cannot select provenance. A registered file
reader yields `project` only with an existing canonical file within the canonical approved root
and a canonical cwd within that root. Missing trust, outside paths, symlink escapes, errors or
failed checks yield `external`. Check before and after the read; this is observed containment,
not filesystem attestation: concurrent external writers and ABA symlink races remain outside
the contract. Generic tool results remain `tool-output`, which has unknown source ancestry;
overflow recovery through `read_output` cannot upgrade external ancestry.

Summary joins recursively inspect every source block, including nested results and prior
summaries. All-user input yields `user`; user/project input yields `project`. External, missing,
generated or tool-output ancestry conservatively yields `external`. This is a source join,
not a permission ranking or proof that project/user content is safe. Empty input is unknown.
Built-in summaries join exactly the summarized inputs and ignore the provider's claimed labels.
Custom compaction cannot choose its output's provenance: structurally unchanged source blocks
recover their recorded labels; ambiguous duplicates join conservatively. New/changed output
inherits the conservative join of all inputs. Prefixes and returned labels prove nothing.
Compaction receives a detached input copy so in-place mutation cannot erase the original floor.
Malformed custom output is rejected with the existing nonfatal compaction-failed event; the
original history remains intact. Aborted post-result provenance checks degrade to external,
never emit a second tool result or rerun its hooks.

Acceptance: real MCP/file/tool runtime results, trusted/untrusted and symlink controls, resumed
canonical messages; nested and repeated summaries, custom mutation/duplicate/spoof controls,
and summary-laundering discrimination in actual next-turn requests. Negative source/summary
mutations must fail named tests and be restored. Full build/typecheck/test, exactly one bounded
independent review, fresh-main exact-head three-platform CI and post-merge CI gate delivery.
Optional polish stays at ROADMAP's end; final receipts belong to this row's PR.
