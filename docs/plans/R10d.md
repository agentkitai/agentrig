# R10d — explicit empirical provider conformance probes

`agentrig doctor --probe` deliberately performs potentially billable network requests to the
resolved main provider entry, after ordinary configuration/trust/credential diagnostics. It
does not construct other role providers, tools, MCP servers or extensions. Plain doctor never
constructs a provider, refreshes auth, performs a model request or writes probe observations.

Core probes at most five outer `stream` invocations, requesting at most 256 output tokens each,
with 256-event/8-tool/16,384-character per-stream collection limits and a 30-second total local
deadline. Cancellation is propagated and a stuck custom iterator cannot stall the runner.
Transient HTTP/stream retries are disabled for the CLI probe; ChatGPT retains one forced 401
refresh/re-request and auth may refresh/persist rotated tokens. Requested output limits do not
constitute a remote billing cap (ChatGPT ignores the parameter); cancellation cannot prove
remote work stopped. Reported usage is aggregated separately from its completeness. Missing,
synthesized, interrupted or retried usage is not presented as known zero cost. No tools execute.

Samples check an exact inert tool request/result acknowledgement, two distinct valid calls in
one response, prompted JSON schema conformance, and repeated stable-request cache reporting.
Prompted JSON matching is empirical; native/wire structured strictness stays explicitly unknown
because ModelRequest exposes no native strict-format control. Completed mismatches are
not-observed; incomplete/error samples are unknown. Positive reported cache counts demonstrate
a cache observation; absent/zero counts cannot disprove caching. These are samples, not universal
guarantees, model attestation or permission authority.

## Cache and consumption

The normal CLI provider construction path reads fresh matching observations and adjusts actual
tools/parallelTools/caching capability booleans for observed/not-observed dimensions. Unknown
dimensions retain their existing configured values, explicitly labelled unverified-configured
per dimension. Context window, pricing, permission and sandbox behavior are unchanged. Direct
SDK constructors retain defaults unless the caller explicitly applies observations.

Mutable local advisory cache: versioned validated JSON, at most 64 entries/128 KiB, 24-hour TTL,
future/stale/corrupt/mismatched entries ignored. The key hashes provider/model/endpoint/tuning
and actual credential material. No raw endpoints, secrets, response text or provider errors are
persisted in reports. ChatGPT matches file-first valid-token/env fallback, without auth refresh
on reads; unavailable or changed-during-probe identity prevents caching. Token rotation can
invalidate a prior entry. The cache is not a server attestation or an isolation boundary.

Writes use exclusive random temporary files and atomic replacement, retaining bounded recent
entries. Concurrent writers may lose another observation (last replacement wins), conservatively
falling back to unverified configuration; no permission record is created or restored. Local
owner edits/global host customization remain trusted. Default provider construction reads only;
only explicit probe writes. Errors are generic to avoid printing credential-bearing URLs/body.
