# E2 — compact outcome reports

One PR, fresh from E1's green merged main. Add a typed report builder and thin evaluator script,
not a serving/export platform. Inputs are bounded validated session logs plus evaluator-owned
configuration, independent-check evidence, outer lifecycle timing and optional auxiliary receipts.

Report task outcome separately from the agent's end reason; preserve behavior/regression/scope/
human lanes and evidence references. Include elapsed wall time through observer/maintenance
settlement, main and auxiliary usage/cost, approvals, tool errors, unintended changes,
interventions and retrieval requests. Count tool requests as requests, not proof of successful
retrieval. Missing checks, lifecycle coverage, auxiliary receipts or usage are explicit unknowns.

Add optional `model.response.usageComplete` so new logs distinguish a provider-reported zero
from omitted/synthesized usage; old logs remain parseable and conservatively unknown. Retries
and interrupted requests never look free. Price only with explicitly supplied per-role/provider/
model rates for every observed token category; no hard-coded current market prices.

Supervisor snapshots replace by run ID. Memory/compaction/backend work not represented in the
session event stream requires evaluator-supplied receipts/coverage; a missing collector cannot
turn it into zero spend. Child session references without their logs make aggregate coverage
incomplete. Do not infer universal instrumentation from one main log.

Validate with known fixture outcomes and real scripted-provider sessions, including missing usage,
partial/retried calls, cache counts, duplicate snapshots, unfinished auxiliary work, omitted child
logs, wrong IDs/config, corrupt/truncated files and independent failure despite `done`. Build,
typecheck, full Node22 suite, bounded Claude review and exact-head PR/main CI before E3.

No paid model calls or benchmark-win claims. E3 needs separately authorized model/role choices,
budgets and spend cap. Small nonblocking improvements stay at the END of ROADMAP.
